# Backend Projects

A collection of backend development projects built while learning Java, Spring Boot, and backend development.

These projects document my progression from core Java and object-oriented programming to building REST APIs and integrating a frontend with a backend.

## Projects

### 1. Student Management System — CLI

A command-line student management system built with Java.

**Concepts practiced:**

- Object-Oriented Programming
- Interfaces
- Inheritance
- ArrayList
- HashMap
- File handling
- Service-layer architecture
- Data validation
- Error handling

[View Project →](./Student-Management-CLI)

### 2. Student Management REST API

A Spring Boot REST API for managing student records, with a simple web frontend served by the Spring Boot application.

**Concepts practiced:**

- Spring Boot
- REST API development
- Dependency Injection
- DTOs and DTO mapping
- Bean Validation
- Global exception handling
- HTTP status codes
- Automated API testing with MockMvc
- Frontend-backend integration
- Git and GitHub

[View Project →](./Student-Management-REST-API)
